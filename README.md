# JobSeek · 校招投递追踪

一个只在本机运行的看板，用来记录校招投递：投了哪家、用的哪版简历、JD 是什么、流程走到哪一步。

- 前端是 Vite + 原生 JS，没有框架和运行时依赖
- 数据存在项目下的 `data/` 目录，PDF 是硬盘上的真实文件，不依赖浏览器缓存
- 仓库里只有代码，`data/` 已加入 `.gitignore`

## 启动

```bash
npm install
npm run dev
```

打开 <http://localhost:5173>。第一次启动会自动创建 `data/db.json`，并写入三个内置流程模板。

> 数据接口只接受 `localhost` 访问，局域网里的其他设备打不开。

## 怎么用

### 看板

看板有六列，只表示大阶段：**待投递 → 已投递 → 笔试/测评 → 面试中 → Offer → 已结束**。

- 卡片可以拖到别的列；拖到「已结束」时要选结果（挂了 / 拒Offer / 放弃 / 无回音）
- 点卡片打开右侧的详情抽屉，所有改动即时保存
- 顶部可以搜索（会搜公司、岗位、城市、备注和每轮的备注），也可以按类别、意向度、简历版本筛选
- 统计条里的「进入面试 / Offer」比例按「已投递」数计算

### 流程节点：应对各家不同的流程

每条投递都有自己的一串流程节点（网申、笔试、一面、交叉面/横向面、HR面……），可以随时插入、删除、调整顺序。每个节点属于某一列，自定义节点可以自己选归属列。

临时多出一轮（比如横向面、加面）时，在前一轮右边点 **＋**，从菜单里选类型，就会插在它后面。

**节点和看板的联动规则**

| 触发 | 效果 |
|---|---|
| 节点标为「已约 / 待结果 / 通过」 | 如果节点所属列在卡片当前列之后，卡片自动前移，不会往回退 |
| 卡片前移（拖拽，或上面的自动前移） | 更早的列里还没结果的节点视为「通过」；移到「已投递」时，网申节点变成「待结果」 |
| 节点标为「未通过」 | 询问是否移到「已结束 · 挂了」 |
| 第一次离开「待投递」 | 如果还没填投递日期，自动填成今天 |

卡片上显示的**当前环节**，是最后一个有进展的节点。如果这个节点已经通过，就改为显示它后面的第一个节点。已约的场次在 48 小时内时，卡片上会标红。

### 简历库

每个简历版本上传一份 PDF，给它起个名字、写个备注，投递时在详情里选用哪个版本。版本上传后**不能替换 PDF**，这样总能查到当初投出去的是哪一版；改了简历就上传一个新版本。每个版本的卡片会显示投了多少次、过筛多少次（进入笔试/测评或更后面的阶段就算过筛）。

### JD

每条投递可以上传一份 JD 的 PDF，点按钮或把文件拖进详情里的 JD 区域都行。

### 流程模板

新建投递时选一个模板，会自动生成流程节点。之后每条投递的流程可以单独修改，不会影响模板。模板可以在「流程模板」页里编辑，也可以把某条投递的流程「另存为模板」。

## 数据与备份

```
data/
├── db.json              # 全部结构化数据（投递、简历版本信息、模板）
├── resumes/<id>.pdf     # 简历 PDF
├── jds/<投递id>.pdf      # JD PDF
└── backups/db-日期.json  # 每天第一次写入前，自动备份上一版 db.json
```

- 写入时先写临时文件再重命名，中途出错也不会把 `db.json` 写坏
- 同时开多个标签页：切回某个标签页时会自动拉取最新数据；万一还是冲突了（带版本号检查），会提示并加载最新版本，不会悄悄覆盖
- 如果 `db.json` 损坏了，可以从 `data/backups/` 拷一份回来
- 想完整备份，直接复制整个 `data/` 目录

## 项目结构

```
server/fileApi.js   Vite 插件：读写 data/ 的本地 API（/api/db、/api/files/:kind/:id）
src/
├── main.js         入口和路由（#/board、#/board/<id>、#/resumes、#/templates）
├── store.js        内存状态 + 串行保存 + 冲突处理
├── actions.js      所有修改数据的操作
├── api.js          fetch 封装
├── model/          看板列、节点类型等常量，流程联动逻辑，内置模板
├── views/          看板、详情抽屉、新建弹窗、简历库、模板页
├── ui/             DOM 工具、弹窗、菜单、提示
└── styles.css      支持浅色和深色模式
```
